## M7 certificate template — the long way round

Worth recording since it took several real iterations, not a straight line:

1. Started with the real `.docx` templates (uploaded as actual OOXML, not
   the flattened text export I'd seen first). Tagged them with
   `docxtemplater`-style `{field}` placeholders, collapsed the scope table
   to a single loop row.
2. Fred pushed back hard, correctly: he wanted the original design (4 fixed
   rows, bilingual FR/EN labels always visible) preserved, not redesigned
   into a dynamic loop. Rebuilt around 4 fixed categories
   (aéronefs/moteurs/composants/spécialisée), 3 fields each — no loop needed.
3. Hit a real docx rendering bug chasing a page-count fix: a blunt "zero all
   paragraph spacing" edit fixed the 2-page overflow but visibly crowded
   text against the page border. Traced it with pixel-level border-overlap
   detection (not just eyeballing) before landing a surgical fix.
4. Fred asked directly whether HTML/CSS would be easier — tried it,
   confirmed `wkhtmltopdf` (the only renderer available in this sandbox) has
   a real, reproducible bug with full-page-height bordered boxes (3 separate
   techniques all failed the same way), while CSS Grid doesn't render at all
   in that old engine.
5. Fred rebuilt the template himself from scratch in HTML — landed on a
   **table-based layout** (not Grid), which sidesteps the old-engine
   compatibility problem entirely, plus a `renderCertificate(data)` JS
   function that populates `[data-field]` nodes. This is the final,
   locked template shape.

## What's built (this session)

- **M6 API**: `site-inspection` module — R3 role reuses staff auth (no
  separate login), payment pattern reused from M5, R3 verdict submission
  auto-closes the phase. Security fix: R3's verdict/note was leaking to
  applicant callers via `authenticateEither` — locked as DN-internal only
  per `modules-feasibility.md`, fixed server-side not just in the UI.
- **M7 API**: `certificates` module — certificate row created at payment
  validation (KPI zero-point), `scopeDetails` is a **fixed 4-category jsonb
  shape, not a dynamic array** (locked with Fred — DN never adds/removes
  categories, only fills qualification/limitations text, "Nil" when N/A),
  generation via Puppeteer (`page.evaluate(renderCertificate)` +
  `page.pdf()`), status lifecycle auto-closes the phase on collection.
- **Admin**: `/demandes/:requestId/demonstration-inspection` (M6) and
  `/demandes/:requestId/delivrance` (M7), both with a "Mes Inspections" R3
  queue page for M6.
- **Portal**: `SiteInspectionSection` and `CertificatesSection` — proof of
  payment upload for both, R3 opinion never shown (M6), certificate document
  never downloadable in-app (M7 — always collected in person).
