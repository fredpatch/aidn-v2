# 2026-07-28 — Workflow hardening + C-V1 document viewer

## Summary

Post-M7 workflow hardening continued after Fred's end-to-end test. This session
focused on making the phase pages answer "what is next, who owns it, and what is
blocking progress?" consistently across M3-M7, then implementing Part C-V1 of the
hardening plan: an integrated document viewer, M5 first.

## Built

- Shared admin `PhaseWorkflowSummary` component:
  - title/description for the next action
  - responsible owner
  - phase status badge
  - blocker copy
  - compact per-phase metrics
- Integrated phase summaries:
  - M3 Preliminary: meeting, declaration, optional report
  - M5 Deep Evaluation: payment and document validation progress
  - M6 Site Inspection: payment, site visit, R3 opinion
  - M7 Certificates: payment, certificate reference, lifecycle status
- M4 Formal Phase retained a dedicated `FormalPhaseSummaryCard` because its DG
  circuit + 11-document checklist has denser business rules than the other phases.

## M4 traceability hardening

- Formal closure UI now mirrors server gates:
  - official letter transmitted to DN
  - 11/11 documents deposited
  - formal meeting resolved
- Compte-rendu remains explicitly optional for closure.
- Document copy now distinguishes `Déposé` from any future review/acceptance
  concept; review is possible but not required.
- Document rows now show current version date and whether earlier versions exist.
- Formal letter circuit now exposes a file URL and version metadata to admin.
- New formal letter uploads now write document versions with owner type
  `dg_circuit_document`, with a guarded fallback for older local rows that may have
  been written under `formal_request_document`.

## Part C-V1 — integrated document viewer

- New reusable admin component: `apps/admin/src/components/documents/DocumentViewer.tsx`.
- First integration: M5 `DocumentEvaluationsCard`.
- Preview rules:
  - PDF: native iframe preview
  - PNG/JPG/JPEG/WEBP: image preview
  - DOC/DOCX/unsupported: no fake rendering; clear fallback to open/download
- Viewer supports close, Escape, "Nouvel onglet", and "Télécharger".
