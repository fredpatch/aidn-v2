    `src/lib/api/preliminary.types.ts`)

  - added Zustand baseline store (`src/lib/stores/ui.store.ts`) for future
    client-state use without mixing with server-state

    `runPreliminaryHelpersTests`

  - migrated `useAuth` to React Query-backed state (`me` + bootstrap status)
  - moved auth HTTP calls to `src/lib/api/auth.api.ts` (`LoginPage` and
    `BootstrapPage` now consume API helpers)
  - moved settings/dev-tools calls to `src/lib/api/settings.api.ts`
  - added `useSystemParameters` + `useDevReset` hooks and query-key
    invalidation for settings page workflows
