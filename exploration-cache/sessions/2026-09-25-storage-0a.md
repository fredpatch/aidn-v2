# Session 2026-09-25 - STORAGE-0A secure file delivery

Spec: `docs/superpowers/specs/2026-09-25-storage-0a-design.md` (incl. §15
amendments A1 dual sessions, A2 signed disposition, A3 rollout order).

## Outcome

Every stored file is served by `/api/files` after the document-specific access
check, or with a 5-minute signed grant. No public `/uploads` (Express, nginx,
Vite). Stored addresses are `/api/files/<uploadAssetId>`.
